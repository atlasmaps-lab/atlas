Canvas: https://claude.ai/artifact/4oA1LjjGoshomWhhbhThPS (direction "sections"). Source: `project/Main.dc.html`.

- Opens from the ⚒ Toolbox button at the right of the bar, as a 420 px dropdown: title, one italic line ("Your choices follow you between apps").
- Sections, closed by default like the final menus (name, italic summary on the right, round arrow; opens in place):
  1. **On the map** — Measure, Lasso, To workspace, Copy view (2-column tool buttons with one line each).
  2. **In <app>** — the app's own tools: Markets = Calculator (DCF, Comparables, Dividend discount, Returns) and Marketplace (buy and sell between people near you, Atlas Social); Politics = Swingometer; Economic = Growth decomposition.
  3. **Time bar** — summary "Style: <name>"; a 2-column grid of thumbnails: Atlas, Frieze, Seismograph, Core sample, Date wheels, Range navigator, Filmstrip, Strategy clock, Watermark, Calendar grid. Picking one changes the time bar live; remembered across apps.
  4. **Look** — Panels (Always shown / Near edges), Hover cards (Simple / Detailed), Estimated values (Hatched / Plain), Grid lines (Off / Lat/long / km), Map colours (land, sea and water, boundaries).
  5. **Feel** — Zoom sensitivity, Cursor sensitivity, Contrast, Overlay strength (0.50), Focus softening (0.25); Reset to defaults.
- Motion: sections cascade in; a section opens in place. PT Serif only; gold for controls; light and dark.
